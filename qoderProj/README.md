## 📖 大衍筮法原理

大衍筮法是《周易》中记载的传统占卜方法，使用50根蓍草进行占卜：

### 基本步骤
1. **准备**：取蓍草50根，去掉1根（象征太极），用49根进行占卜
2. **三变过程**：
   - 将49根蓍草随机分为两堆
   - 从右堆取1根放在手指间
   - 用4除左堆和右堆，取余数
   - 重复此过程三次
3. **确定爻值**：根据三次变化后剩余的蓍草总数确定爻的性质
4. **完成六爻**：重复六次完整过程，得到完整卦象

### 爻值对应关系
- **36根** → 老阳（9）- 变爻 ━━━━━━━ ○
- **32根** → 少阴（8）- 静爻 ━━━  ━━━
- **28根** → 少阳（7）- 静爻 ━━━━━━━
- **24根** → 老阴（6）- 变爻 ━━━  ━━━ ×
