# 贡献者行为准则 Contributor Code of Conduct

## 我们的承诺

为了营造一个开放且受欢迎的环境，我们作为贡献者和维护者承诺：不论年龄、体型、身体健全与否、民族、性别认同和表达（方式）、经验水平、教育程度、社会经济地位、国籍、个人形象、种族、宗教信仰及性取向如何，参与我们项目和社区的每个人都免遭骚扰。

## 我们的标准

有助于创造积极环境的行为包括但不限于：

* 使用友好且包容的措辞
* 尊重不同的观点和经验
* 优雅地接受有用的批评
* 关注对社区最有利的事情
* 与其他社区成员友善相处

不可接受的行为包括但不限于：

* 发布与性有关的言论或图像，以及不受欢迎的性关注或性挑逗
* 恶意中伤、侮辱性/贬损性评论，人身及政治攻击
* 公然或隐私骚扰
* 未经明确许可，发布他人的资料，如住址、电子邮箱等
* 其他可能被合理认定为不当或者违法的行为

## 我们的责任

项目维护者有责任为"可接受行为"的标准做出诠释，并且在遇到不当行为的时候，他们将采取适当且公平的纠正措施。

项目维护者有权利也有责任去删除、编辑、拒绝违背此行为标准的评论（comments）、提交（commits）、代码、wiki 编辑、问题（issues）等贡献；当认为有必要的时候，暂时或者永久地禁止任何他们认为行为不当、威胁、冒犯、有害的贡献者。

## 适用范围

此行为标准适用于本项目的所有空间，也适用于在公共场所代表该项目或其社区的个人。代表项目或社区的情形包括但不限于：使用项目的官方电子邮件、通过官方媒体账号发布消息、作为指定代表参与在线或线下活动等。项目维护者可对"代表本项目"进行进一步的定义和解释。

## 贯彻落实

可以通过 [项目邮箱] 或 GitHub Issues 向项目团队举报滥用、骚扰或其他不当行为。所有投诉都将被审查和调查，并将做出必要且适当的回应。项目团队有义务为举报者保密。具体的贯彻落实方针或将单独发布。

对于不真诚遵守或执行此行为标准的项目维护者，可能面临由项目领导成员决定的暂时或永久的后果。

## 特别说明

### 文化敏感性

考虑到本项目涉及中国传统《周易》文化，我们特别强调：

* 尊重不同的文化背景和信仰
* 避免对传统文化的不当评论或调侃
* 以学术和研究的态度讨论相关话题
* 理解占卜和易学的文化意义和历史价值

### 学术交流

在讨论易经、占卜等相关话题时：

* 保持客观和理性的态度
* 基于历史文献和学术研究进行讨论
* 尊重不同的学术观点和解释
* 避免迷信化或商业化的倾向
